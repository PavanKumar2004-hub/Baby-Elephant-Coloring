## 🚀 Quick Start & Development

### 1. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized static bundle in `dist/`, ready for 1-click deployment to Vercel, Cloudflare Pages, Netlify, or AWS S3.

### 3. Preview Production Build
```bash
npm run preview
```

## 💰 Monetization Architecture: Maximizing Revenue While Keeping Free Access

The user's core rule: **"All content is 100% free until it is non-commercial with respective guidelines."**

1. **100% Free Non-Commercial Access**:
   - Parents, children, and school teachers enjoy unlimited free coloring, single prints, classroom 2-up half sheets, and diplomas.
2. **Commercial Use License Generator ($9.99 - $99.00)**:
   - For creators selling coloring books on **Amazon KDP**, printable sheets on **Etsy**, daycare curricula, or physical merchandise (t-shirts, mugs, stickers).
   - Generates an official, cryptographically signed **Certificate of Commercial License (PDF)** with unique License ID.
3. **Baby Elephant VIP Family Club ($4.99/mo)**:
   - Ad-free experience across the entire site.
   - Early access to new monthly storybook drops.
   - 20% discount on commercial license bundles.
4. **"Buy Me a Box of Crayons" Tip Jar ($3, $5, $10)**:
   - Encourages micro-donations from happy parents and educators.
5. **COPPA-Compliant Family-Safe Art Sponsor Slots**:
   - High-yield ethical ad slots for non-toxic washable art supplies and children's books.

## 🛠️ Complete Admin Portal (`/admin`)

Click the **Admin Portal** button in the header or footer to access:
- **Overview & KPIs**: Real-time traffic, PDF downloads count, online coloring plays, total revenue counter.
- **Coloring Sheets CMS**: Add, edit, delete sheets, upload new line-art outlines, and attach finished color reference guides.
- **Commercial Licenses Audit Registry**: Search and verify customer license keys, activate/revoke licenses, and re-download official legal certificates.
- **Pricing & Policy Settings**: Adjust commercial licensing fees and update COPPA statements.
